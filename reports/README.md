# Tıklama Raporları

Raporlar sunucu tarafında üretilir. Tarayıcının localStorage/cache alanında rapor tutulmaz.

- `click-report.html`: sıralı, okunabilir HTML5 raporu
- `click-report.txt`: aynı kayıtların düz metin karşılığı

GitHub'a yayınlamak için `GITHUB_TOKEN` ve `REPORT_REPO` ortam değişkenleri gerekir. Rapor deposunun private olması önerilir.
